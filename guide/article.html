常见问题

1安装与更新

  1. 下载最新版：打开百度网盘（提取码 1234），下载 zip 并解压到固定目录（内含 manifest.json）。也可在历史版本页点击「下载最新版」。
  2. chrome://extensions/ → 开启开发者模式 → 加载已解压的扩展程序。
  3. 访问 Temu 商品详情页，确认出现右侧「Temu 收藏夹」侧栏与「收藏商品」悬浮按钮。
  4. 更新：下载新版 → 扩展页点「重新加载」或重新加载文件夹。
💡 采集 UI 出现在 Temu 前台、1688、Shein、亚马逊、极鲸云等；卖家后台 / 店小秘仅加载阈值工具，不显示采集侧栏。

2验证码与会员

验证流程

  1. 首次进入采集页弹出「验证」窗口，记录用户 ID（10 位数字，可点复制按钮）并办理验证码。
  2. 输入验证码 →「确认」；「获取验证码 →」跳转办理页；「联系客服」扫码咨询。
  3. 点击侧栏会员 badge 查看到期时间、用户 ID，可「续费 / 升级」。
  4. 输入 FREE3DAYS 可体验 1 天青铜（每设备一次）。

3侧栏总览（Temu 收藏夹）

在 Temu 商品页左下角点击「收藏商品 ↑」将商品加入右侧「未导出商品」列表；侧栏是采集、编辑与发布的主控制台。

图 1 标注说明
  1. 1收藏商品 — Temu 详情页左下角蓝色悬浮按钮，点击开始采集当前商品。
  2. 2会员状态 — 如「黄金会员 · 36 天后过期」；点击查看详情、用户 ID、续费。
  3. 3清理缓存 / 操作说明 — 无法访问 Temu 前台时先清理缓存；「操作说明」打开本站点。
  4. 4齿轮 ⚙️ — 打开「功能设置」面板（图 2～6 均在此面板内）。
  5. 5托管模式 — 单模式每次只选一个平台；多模式可同时勾选多个平台并行发布。
  6. 6发布模式 — 店小秘草稿箱先存草稿；直接发布提交到所选店铺。
  7. 7平台卡片 — 全托管 / 半托管 / 亚马逊 / Shein，当前选中项有蓝色边框。
  8. 8未导出商品 (N) — 已采集、尚未导出的列表；工具栏有自动选择与固定类目。
  9. 9功能按钮区 — 导出 Excel、历史、批量编辑、删除全部、处理失败、AI 优化、导入商品、更新店铺。
  10. 10店铺下拉 + 直接发布 — 选择目标店铺后点橙色「直接发布」；系统按约 3096KB 体积上限自动计算本批可发数量，超限商品留在未导出列表等待下一批。
  11. 11商品卡片 — 显示缩略图、标题、价格、销量；右侧「删除」可移出列表。

页面辅助功能

  • Temu 回到顶部 — 消费者端 Temu 页右下角浮动按钮，长列表快速回顶（与侧栏位置自动避让）
  • 侧栏回到顶部 — 侧栏内容区滚动较深时，侧栏内也会出现回顶按钮
  • 设置齿轮触发条 — 页面右侧边缘有一条细竖条，点击可显示/隐藏「功能设置」齿轮按钮（齿轮被隐藏时使用）

  • ESC 键 — 优先关闭商品详情、功能设置等弹层，再折叠侧栏（详见快捷键）
  • 扩展调试日志 — 功能设置中开启后，控制台输出 [采集助手] 前缀日志，便于排查问题
采集功能

单品 / 列表页采集

商品详情页

  1. 打开 Temu 商品详情页，点击左下角「收藏商品 ↑」悬浮按钮（见图 1）。
  2. 采集中显示进度，成功后 toast 提示，商品进入侧栏「未导出商品」。
  3. 每采集 1 个商品消耗 1 点（钻石会员不限）。
  4. 若开启「采集时自动」AI 选项，采集完成后自动执行标题重写 / 背景替换等。

Temu 列表 / 搜索页

  1. 列表每个商品卡片上注入「+ 采集」按钮，无需进详情即可采集。
  2. 已入库显示「已采集」；重复采集会询问是否覆盖。
  3. 极鲸云 API 快速采集 — 若已配置极鲸云 Token 且会员允许，列表页「+ 采集」会直接调用极鲸云 API 拉取完整商品数据入库（比打开详情页更快）；未配置 Token 时提示去多链接面板「🔑 获取 Token」。

1688 / Shein / 亚马逊等

在对应平台商品页同样显示「收藏商品」与侧栏，采集流程一致，发布时按所选托管模式处理。

多链接批量采集

入口：悬浮「收藏商品」旁的向上箭头 → 打开「多链接批量采集」面板。

  • 链接输入区 — 每行一条链接；支持完整 URL、纯 goods_id、goods_id= 格式
  • 抓取当前页 — 从当前 Temu 列表页抓取商品链接
  • 导入表格 — 从 Excel / CSV 导入链接列表
  • 采集后自动保存链接 — 完成后保存链接到本地
  • 仅采集页面数据 — 只解析 DOM，不调用 Temu 内部 API（更稳、稍慢）
  • 随机等待时间 — 每条完成后随机等待 N～M 秒，降低风控（建议 ≥12 秒）
  • 筛选条件 — 销量、评论率、评分、价格区间、售出率等（仅「抓取当前页」生效）
  • 🚀 开始批量采集 / 停止采集 — 显示进度、当前 URL、实时日志
  • 链接管理 — 保存 / 复制 / 清空链接；可设每次复制数量、跳过已复制
  • 📋 抓取历史 — 查看历史抓取记录
  • ❓ 格式帮助 — 支持的链接格式说明

抓取当前页 · 筛选条件（全部）

仅在使用「抓取当前页」时生效，手动粘贴链接批量采集时不生效。

采集中进度面板

  • 显示当前进度 x / 总数、百分比进度条
  • 显示当前处理 URL与已用时间
  • 实时日志 — 每条成功 / 失败记录，含跳过已入库提示

链接管理（折叠区）

  • 每次复制数量 — 批量复制链接时的条数上限
  • 跳过已复制项 — 复制时忽略已复制过的链接
  • 💾 保存链接 — 持久化到浏览器存储
  • 📋 复制链接 — 按设置数量复制到剪贴板
  • 🗑️ 清空 — 清空已保存链接（不可恢复）
  • 🔄 重置状态 — 清空「已复制」标记，不删链接本身

极鲸云 / GeekBI 采集

在多链接面板勾选「极鲸云接口采集」，通过极鲸云 API 拉取全量商品数据，无需逐个开标签页。

  • 🔑 获取 Token — 多链接面板标题栏配置极鲸云 Token（必填）
  • GeekBI 页面自动提取 — 登录 geekbi.com 后，扩展会自动扫描 localStorage / Cookie 中的 Token；也可在 AI 设置 → 扩展工具手动粘贴
  • 体验档 — 极鲸云 5 次/天；钻石会员按验证码配置次数（100～20 万/天或不限）
  • GeekBI 站点 — 在 geekbi.com 可配合极鲸云批量保存商品到选品流程
  • Token 持久化 — 可通过功能设置「导入 / 导出全部」或 AI 设置「导出配置」备份 Token
  • 批量标签页采集 — 非极鲸云模式下，后台可自动跳转商品页采集并返回列表（由多链接批量触发）

图片编辑器

「编辑图片」打开独立编辑器，保存后写回商品主图。主要功能：

  • 马赛克 / 模糊 / 画笔 — 局部涂抹遮挡

  • 滤镜效果 — 多种图像滤镜
  • 调整尺寸 — 修改输出像素尺寸
  • 撤销 / 重做 — Ctrl+Z / Ctrl+Y；Ctrl+滚轮 缩放，Ctrl+拖拽 平移画布

亚马逊模式

详情中可查看 AI 生成的描述 / 五要点 / 关键词，支持翻译为中文预览；模板填充与发布时会使用这些数据。

底部「保存修改」将编辑写回本地商品数据。

固定类目与固定属性

类目模式切换

未导出列表工具栏：自动选择（按采集数据智能匹配） / 固定类目（始终用指定类目）。

  1. 切到「固定类目」→ 点「选择」打开类目树形选择器（支持搜索）。
  2. 选定后工具栏显示类目名称；Temu / Shein / 亚马逊各自独立记忆。
  3. 点「固定属性(N)」打开属性配置弹窗：带 * 的必填属性可指定固定值，留空则发布时自动随机。

店铺多选

店铺下拉支持全选 / 取消全选多店铺；仅一个店铺时会自动选中并记忆。

卖家后台 · 申报价格阈值

申报价格阈值工具

适用于 agentseller.temu.com、seller.kuajingmaihuo.com 等卖家后台。需付费会员（非体验档）

入口：页面右下角「申报价格阈值设置」浮动按钮（可在功能设置中开关显示）。

基础设置

  • 利润率阈值 (%) — 达标则自动接受申报价
  • 成本价模式 — 自动获取 1688 价 / 固定成本 / 价格差异百分比
  • 每次减价百分比 — 利润率不足时逐步降价
  • 最多执行次数 / 执行间隔 — 控制自动核价轮次
  • 达到最大次数时 — 拒绝申报价 / 跳过不处理
  • 开始执行 / 停止执行

定时任务

  • 启用定时任务 — 定时一键拒绝调价
  • 间隔执行 / 每天定时
  • 紧急停止
  • 自动移除营销弹窗 — 隐藏卖家中心营销浮层

快捷工具 Tab

  • 一键拒绝调价 — 拒绝所有待处理调价
  • 清除弹窗
  • 待发货列表 — SKC/SKU、换仓、约快递、导出 JSON（见下节明细）
  • 备货单列表 — 同步卖家中心备货子单，支持搜索、筛选、批量加入发货台（见下节明细）
  • 核价成功数据 — 批量查询、上传飞书、导出 CSV、查看供应商
  • 功能设置 — 打开采集端功能设置
  • 核价日志 📋 — 核价 / 飞书 / 1688 / 系统日志
  • 执行记录 📊 — 自动核价轮次历史，可导出 CSV
💡 店小秘域名 (dianxiaomi.com) 会自动清理烦人弹窗，不显示采集侧栏。

域名限制说明

部分工具必须在正确卖家域名使用，否则会提示跳转：

  • 待发货列表 / 备货单列表 — 需在 agentseller.temu.com 卖家中心
  • 备货单列表 — 跳转备货管理子单页

待发货列表（明细）

  • 查看 SKC / SKU 待发货数量，复制 ID
  • 导出 JSON — 按 SKC 分组复制 JSON 数据
  • 换仓 — 修改发货仓库
  • 约快递 — 预约快递相关操作

备货单列表（明细）

阈值工具 → 备货单列表，需在 agentseller.temu.com 卖家中心打开。弹窗与卖家中心备货管理数据同步，便于批量操作。

  • 三个主 Tab — 紧急备货 / 普通备货 / 定制品；普通备货下还有「待创建」「待发货」子 Tab
  • 搜索 — 备货单号 / SKC / 商品名；支持仓库、类目、超时、今日可发、标签（履约考核 / VMI / JIT）、状态等筛选
  • 列表字段 — 备货单号、商品图与 SKC、状态时间线（发货 / 到货截止）、SKU 明细、申报价、库存水位
  • 单条操作 — 备货管理、修改数量、加入发货台、操作记录；单号旁 📋 可复制
  • 加入发货台 — 「待创建」状态会先自动接单，再校验 restrictionReason，确认后提交；不可加入时会显示原因
  • 批量操作 — 勾选多行 → 底部批量加入发货台或批量取消备货单
  • 分页 — 每页 10 / 20 / 40 / 100 条，支持首页 / 末页 / 跳转页码

核价成功数据（明细）

  • 一键查询全部 — 批量查未查询 SKU 的 1688 成本
  • 上传全部到飞书 — 需先配置飞书「核价数据」表格
  • 导出 CSV、导入已导出 SKC — 数据管理
  • 查看供应商 — 单条 SKU 供应商信息
  • 刷新 / 清除本地缓存

核价日志 / 执行记录

  • 核价日志 — 筛选：核价决策 / 飞书 / 1688 查询 / 系统；含错误详情列
  • 执行记录 — 自动核价每轮统计；刷新、清空、导出 CSV、删除单条

阈值浮动按钮

  • 右下角「申报价格阈值设置」可点 × 关闭；在功能设置重新开启
  • 运行中显示浮动停止按钮，可紧急停止自动核价

常见问题

无法访问 Temu 前台

  1. 侧栏「清理缓存」→ 关闭所有 Temu 标签 → 重开 www.temu.com
  2. 仍失败：开 VPN 后访问；清理后可能需重新登录

验证后无侧栏 / 无齿轮 / 双面板

  1. chrome://extensions/ 重新加载扩展 → 刷新页面

点数 / 极鲸云用完

体验档 20 点/天、极鲸云 5 次/天，次日重置；或输入更高档位验证码升级。

发布失败

  1. 检查店小秘 API 与店铺；点「处理失败」看原因
  2. 固定类目 / 补全默认属性；减少单次发布数量

体验档提示「请开通会员」

卖家后台阈值、部分高级工具需青铜及以上；采集侧栏基础功能在体验档可用（受点数限制）。
